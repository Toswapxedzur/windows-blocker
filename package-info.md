# windowsBlocker — Windows Vault (native Windows app)

> 🤖 **AI protocol:** Read `../package-info.md` (group), the group `AGENTS.md`, and `../misc/project-memory/PROJECT-MEMORY.md` before working here. Update this file when the folder changes. Never delete without owner consent; keep secrets out of git.

- **Icon palette:** the WPF project embeds bright `Assets/windows-vault.ico`;
  `Assets/windows-vault-dark.svg` is retained for the website. See
  `src/WindowsBlocker/Assets/package-info.md`.

- **What:** the native Windows member (public name **Windows Vault**): .NET 8 WPF app with a WebView2 editor (mirrored extension UI in `src/WindowsBlocker/WebAssets`), app inventory, enforcement, custom-rule runtime, the authenticated protocol-4 hub, and the shared Swift Classifier/Activity worker.
- **Own git repo:** `Toswapxedzur/windows-blocker`; version source of truth = `<Version>` in `src/WindowsBlocker/WindowsBlocker.csproj`. The 0.3.0 parity candidate is in progress on `feature/ai-content-parity`; generated editor assets alone do not establish native AI or rule parity.
- **Build/test:** needs Windows + .NET 8 SDK (`WindowsBlocker.sln`). Real-Windows testing: the existing Windows 11 VM on Mini2. All builds/tests run on Mini2, including Node contracts and native Windows tests; no laptop testing. `sync-webui.sh` generates canonical browser editor, Mac native shim/scenes, languages, and the native rule engine. `tests/runner-custom-rule-stress.js`, `runner-rule-worker.js`, and `runner-editor-syntax.js` exercise the current raw-event API, disposable-worker isolation, and native storage/log callbacks on Mini2.

- **Custom-rule logs (2026-11-05):** the shared Mac/Windows WebView shim persists `v.log` and explicit `page-error` entries by immutable group ID in a versioned localStorage document (200 per group, 2 MiB total, oldest first). It imports valid pre-Beta unversioned logs and refuses unsupported or malformed saved data without overwriting it. The Mac `RuleLogShim.test.js` contract runs against both shims on Mini2.
- **Generated assets:** editor/scenes/language catalogs and Classifier assets are generated by `sync-webui.sh`; change their canonical browser/Mac sources. The AI selector script and one desktop configuration tag are part of this generated contract. Worker host/transport and native `.cs` files remain Windows-owned.
- **Folders:** `src/WindowsBlocker/` (`Core`, `Enforcement`, `Rules`, `Bridge`, `SelfPreservation`, `WebUI`, `WebAssets` incl. UI language catalogs and fixed app-language `manual/` and `code-manual/` guides, `Assets/` official Windows icon), `src/VaultNativeHost/` (browser authentication and bundled MCP stdio helper), `scripts/development/` (Mini2 build/launch/registration), `scripts/classifier-worker/` (shared Swift worker and dependency bundle), `scripts/release/` (self-contained x64 package/current-user installer), `tools/` (public MCP registry export), `tests/`, `i18n-docs/`, `localization/` (canonical Windows user/code guides for the fixed app language set).

- **English preparation (2026-10-01):** English UI terminology is aligned without importing the newer Mac/browser runtime. Apps and Windows Vault name the native target and product; PIN-protected freeze retains the existing Windows behavior.

- **Info explanations (2026-10-01):** English-only help uses the shared standalone vault-info component, without importing newer browser dropdown/runtime behavior.

- **Field Info (2026-10-02):** 10px blue-gray icons retain a 24px invisible hit area. English field explanations are explicit; built-in settings, names, switches, searches and picker fields use the shared component. Other locales retain inline help.

- **Compact Info (2026-10-02):** 10px icons retain a 24px click area; explanations use 12px text in a softly shaded, 260px-wide popup with tighter padding. English search copy is concise.
