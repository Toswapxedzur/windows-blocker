# Worker runtime notices

Original license and notice texts for the official Swift 6.4.0 Windows runtime.
The build copies this directory into `ClassifierWorker/Notices` and adds the
actual pinned llama.cpp and resolved Swift package licenses before hashing it.

- `Swift-LICENSE.txt` — Swift runtime and runtime library exception.
- `Foundation-LICENSE.txt` — corelibs Foundation and FoundationNetworking.
- `FoundationEssentials-LICENSE.txt`, `FoundationEssentials-NOTICE.txt` — the
  Swift Foundation implementation and its upstream notices.
- `FoundationICU-LICENSE.txt` — Swift's Foundation ICU wrapper.
- `ICU-LICENSE.txt` — Unicode ICU 76.1 and its included third-party notices.
- `Dispatch-LICENSE.txt` — libdispatch and BlocksRuntime.
- `curl-COPYING.txt`, `brotli-LICENSE.txt`, `zlib-LICENSE.txt`,
  `libxml2-Copyright.txt` — dependencies included in the official runtime.
- `sources.md` — exact official repository references for these texts.
- `package-info.md` — this direct-content map.
