# Windows Vault app icon

`windows-vault.svg`, `windows-vault-master.png`, and `windows-vault.ico` are the
bright app icon. The WPF project embeds the ICO. The inverse-name companion
uses the same bright palette. `windows-vault-dark.svg` preserves the exact dark
website source. The visible tile outline is disabled without changing the
published 0.3.1 icon's geometry. The canonical bright SVG is mirrored in
`customBlocker/tools/branding/windows-vault-bright.svg`; regenerate on Mini2.
