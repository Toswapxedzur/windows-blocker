# Windows Vault 用户手册

Windows Vault 有三个页面：**Vault** 屏蔽原生应用，**分类器**为受支持的浏览器内容打标，**活动**显示已记录的使用情况。浏览器扩展采集受支持的内容并执行浏览器屏蔽。请在所用浏览器中安装并连接扩展。

## 快速开始

1. 在 **Vault** 中添加屏蔽组和应用目标，然后使用 + 选择器选择应用。
2. 选择组的屏蔽行为并启用它。
3. 在**分类器**中创建组，选择平台，并添加标签和说明。
4. 选择本地模型档位，必要时下载模型。在分类器设置中启用打标，并恢复该组。
5. 在已连接的浏览器中打开受支持的内容。如果希望标签控制屏蔽，请在浏览器屏蔽组中配置标签筛选。

## 屏蔽组

**屏蔽组**执行屏蔽策略。**分类器组**为内容分配标签，本身不会屏蔽任何内容。

1. 添加屏蔽组并为其命名。
2. 在**应用于**中选择目标。
3. 选择屏蔽生效的条件，再设置时间安排或可用时长。
4. 启用该组。它的目标共用该组的策略。

常规修改会自动保存。出现错误说明修改未被接受；请纠正字段后重试。停用组会停止执行策略，但保留配置。**删除组**会将其移除。拖动组可调整顺序。多个组可以同时应用于同一目标；暂缓其中一个组不会解除其他组的屏蔽。

**导出**复制组的配置。**导入**会在确认后替换所选组的配置。

### 可用时长和时间安排

**立即屏蔽**会在已启用的组匹配目标且处于生效时间内时执行屏蔽。**可用时长用尽后屏蔽**允许先使用匹配的目标，直至可用时长耗尽。

可用时长以分钟设置，重置间隔以小时设置。滚动限制统计最近一个时间窗口内的使用。午夜重置会在本地午夜开始新周期，也适用于滚动限制。

选择生效的星期几，并可添加本地时间段，每行一个，例如 **09:00-12:00**。时间段列表为空时，在所选日期全天生效。同一日期的结束时间必须晚于开始时间；跨夜安排需拆分到不同日期。

### 暂缓

在每个屏蔽组中配置暂缓。**暂停屏蔽**会在指定时长内暂停该组的策略。**增加可用时长**为有时间限制的组增加可使用的分钟数。只有实际消耗的额外时长才计入暂缓使用时间。未用完的额外时长在下次重置时失效；使用滚动限制时，在一个窗口后失效，若启用了午夜重置，也可能更早失效。

**启动延迟**会推迟暂缓生效，等待期间仍执行屏蔽。**冷却时间**是一次暂缓结束后，再次请求暂缓前必须等待的时间。**所需确认次数**设置确认步骤的数量。冻结组只有在冻结前允许暂缓，才能使用暂缓。

### 冻结和 PIN

**冻结**会阻止常规修改。解冻需要进行十次确认，每次间隔五秒，并满足已设置的等待时长和六位 PIN 条件。**解冻前等待**接受 0–72 小时；0 表示不增加等待时间。

冻结期间可以延长等待时间，也可以在尚未设置 PIN 时添加 PIN。解冻前不能减弱这些条件。删除同样受剩余等待时间和 PIN 限制。

### 关联组

使用**关联**连接其他 Vault 程序中明确选定的组。关联组共享名称、受支持的策略设置、目标、使用量和冻结条件。每个程序编辑并执行它支持的目标类型；其他目标条目仍保留供关联程序使用。解除关联后，各组及其设置都会保留。

若关联成员离线，可能无法编辑。打开 Windows Vault 和关联的浏览器以重新连接。成员离线时，本地已保存的策略仍可能继续执行。

## 获取帮助

点击字段旁的小 **i** 查看说明。点击外部或按 Escape 关闭说明。列表位于可滚动的区域中；滚动列表可查看其他条目。搜索只筛选显示的条目，不会删除条目。

自定义规则有单独的[代码手册](../code-manual/zh.md)，介绍编辑器、规则启用、日志、文件访问和受支持的 API。

## 原生应用

使用应用目标的 + 选择器选择已安装的应用。**屏蔽除此之外的所有应用**将列表用作允许列表。系统应用、浏览器和 Vault 自身不参与原生应用屏蔽。

对于被屏蔽的应用，Vault 会请求它退出。**再次请求被屏蔽应用退出的间隔（分钟）**控制重试。网站重定向、页面暂停和内容隐藏由浏览器扩展执行，不会变成原生应用操作。

## 内容标记

每个 内容标记 使用自己的标签树和模型设置为分配平台的内容添加标签。每个平台只能属于一个组；创建时选择，之后不能更改。拦截组的时间表和筛选器不控制 tagging。在 设置 中启用 tagging，并分别使用各组的 **暂停标记 / 继续标记**。在 **活动 → 记录** 中关闭平台 feed 记录也会停止该 feed 的 tagging。

### 标签和模型设置

创建标签、描述含义并在标签树中设置或移除父级。拖动标签可移动其分支。清晰的说明有助于模型区分相似标签。各组设置相互独立。**最低标签置信度** 设置每个预测标签所需的证据等级，范围为 1–5；新组从 4（有力支持）开始。没有目标标签数量，条目也可以没有标签。**标记说明** 保存该组的偏好。常规编辑自动保存；每个组使用明确选择的 connection、model 和 reasoning effort。

### AI 连接

设置 提供 ChatGPT subscription、OpenAI API、Gemini API 和 Grok API。该订阅使用 Vault 自己的登录方式和符合条件的计划。API 密钥按所选提供商的 API 计费和使用限制执行。选择提供商并在共享下拉菜单正下方输入密钥；密钥修改会自动保存，清空字段会删除密钥。选择 **获取模型列表** 获取模型，然后在 内容标记 或 custom-rule 组中选择模型；获取模型不会替你选择。

**推理强度** 控制所选模型的思考程度：支持时可选 Model default、Low、Medium 或 High。新选择从 Medium 开始，已有选择保持保存状态。较高强度可能增加耗时和 token 用量。Tagging 始终启用网页搜索，由模型决定何时使用。请选择支持搜索和结构化 tagging 的模型。请求失败或不可用时会保留有效的缓存结果；新条目会保持未解决，直到选择 **重试云端分类**。Vault 不会自动切换提供商；每个连接有各自的重试间隔和次数上限。在浏览器扩展中点击 **+ tag**，搜索并选择标签以添加；使用移除控件，或选中标签后按一次 Delete 删除。**未标记** 表示 tagging 已完成但没有标签；**正在标记** 表示结果仍在等待。你所做的更正对该条目具有决定性。


## 活动

活动 在本地记录已启用应用的使用情况、网站访问和受支持的 **已查看内容**。图表反映记录的数据；空白不代表 PC 一定处于空闲状态。选择日期范围。**时间线** 按一天中的时刻显示使用情况；**总计** 汇总时长；**时间间隔** 将每个区间的使用合并为竖直块。**颜色** 是可点击的图例；选择来源以聚焦图表。选择某天可查看从该日起的使用情况。

### 活动 组

创建组，在 Usage 中并排显示所选应用和网站。**Merge** 在整个 活动 中为成员使用同一名称和颜色。活动 组用于整理记录的使用情况，与拦截组和 内容标记 不同。请在编辑器中明确点击 **Save** 保存。

### 记录和保留期限

在 **记录** 中按类别或单个来源启用或关闭记录。**保留** 控制历史记录的保留时长；**永久** 表示不会自动过期。单项选择可以遵循更广泛的设置。关闭记录会停止新增记录；删除历史记录会移除已记录条目。平台 feed 会收集受支持页面上显示的内容，无论页面是否打开。开启记录时，**支持标记** feed 可向 内容标记 提供内容。其保留设置与应用和网站使用情况分开。暂停 tagging 组本身不会关闭记录。

## 设置

在 设置 中选择界面语言。字段说明通过所选语言的 Info 按钮提供。

## 保存和故障排查

常规 Vault 和分类器修改会自动保存。活动组编辑使用**保存**。添加、删除、下载模型、测试连接和获取模型列表仍需要明确操作。

若没有标签，请检查浏览器连接、全局打标开关、组的暂停状态、平台记录和模型下载。若研究不运行，请检查授权、组的选择、提供商凭证、研究模型和研究状态。若无法编辑关联组，请根据提示重新连接其程序或解冻。
