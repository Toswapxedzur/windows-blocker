# Windows Vaultユーザーマニュアル

Windows Vaultには3つのページがあります。**Vault**はネイティブアプリをブロックし、**分類器**は対応ブラウザーコンテンツにタグを付け、**アクティビティ**は記録した使用状況を表示します。ブラウザー拡張機能は対応コンテンツを収集し、ブラウザーのブロックを適用します。使用するブラウザーにインストールして接続してください。

## クイックスタート

1. **Vault**でブロックグループとApps対象を追加し、+ピッカーでアプリを選びます。
2. グループのブロック動作を選んで有効にします。
3. **分類器**でグループを作成し、プラットフォームを選び、説明を付けてタグを追加します。
4. ローカルモデルの階層を選び、必要ならダウンロードします。分類器設定でタグ付けを有効にしてグループを再開します。
5. 接続済みブラウザーで対応コンテンツを開きます。タグでブロックを制御する場合は、ブラウザーのブロックグループでタグフィルターを設定します。

## ブロックグループ

**ブロックグループ**はブロックポリシーを適用します。**分類器グループ**はコンテンツにタグを付けますが、それ自体は何もブロックしません。

1. ブロックグループを追加して名前を付けます。
2. **適用先**で対象を選びます。
3. ブロックを適用するタイミングを選び、必要に応じてスケジュールや時間枠を設定します。
4. グループを有効にします。対象にはグループのポリシーが適用されます。

通常の編集は自動保存されます。エラーが出た場合、編集は受け付けられていません。項目を修正して再試行してください。設定を残したままポリシーを止めるにはグループを無効にします。**グループを削除**すると取り除かれます。ドラッグして順序を変えます。同じ対象に複数のグループを適用できます。一つを一時停止しても、別のグループのブロックは解除されません。

**エクスポート**はグループ設定をコピーします。**インポート**は確認後、選択したグループの設定を置き換えます。

### 時間枠とスケジュール

**すぐにブロック**は、有効なグループの対象が一致し、スケジュールが有効なときに適用されます。**時間枠を使い切ったらブロック**は、枠がなくなるまで一致する利用を許可します。

時間枠は分、リセット間隔は時間で設定します。ローリング制限は直前のウィンドウ内の利用を数えます。深夜にリセットすると、ローリング制限も含め、現地時間の午前0時から新しい期間が始まります。

有効な曜日と任意の現地時間ウィンドウを選び、1行に1つ入力します（例：**09:00-12:00**）。ウィンドウが空なら選択した曜日の終日が対象です。同じ日の終了時刻は開始時刻より後にしてください。夜をまたぐスケジュールは日ごとに分けます。

### 一時猶予

各ブロックグループで一時猶予を設定します。**ブロックを一時停止**は指定時間、そのグループのポリシーを停止します。**時間枠に追加**は、時間制限のあるグループに利用可能な分数を加えます。追加分のうち実際に使った時間だけが一時猶予時間に数えられます。未使用分は次のリセット時に失効します。ローリング制限では1ウィンドウ後、設定によってはそれより早い深夜に失効します。

**有効化の遅延**中もブロックは続き、一時猶予の開始が遅れます。**クールダウン**は一時猶予終了後、次の要求までの待ち時間です。**必要な確認回数**は確認手順の数を設定します。凍結中のグループで利用できるのは、凍結前に許可されていた場合だけです。

### 編集のロックとPIN

**凍結**すると通常の編集ができなくなります。解除には5秒間隔で10回の確認が必要で、設定した待ち時間と6桁のPINも求められます。**解除前の待ち時間**は0～72時間です。0なら追加の待ち時間はありません。

凍結中は待ち時間を延長でき、PINがなければ追加できます。グループを解除するまで、これらの条件を緩和できません。削除にも残りの待ち時間とPINが適用されます。

### グループのリンク

**リンク**を使うと、他のVaultプログラムで明示的に選択したグループを接続できます。リンクしたグループは名前、対応するポリシー設定、対象、使用状況、凍結条件を共有します。各プログラムは対応する対象タイプを編集・適用し、その他の対象項目はリンク先で利用できます。リンクを解除しても各グループと設定は残ります。

リンクされたメンバーがオフラインの場合、編集できないことがあります。再接続するにはWindows Vaultとリンク先ブラウザーを開きます。メンバーがオフラインでも、ローカル保存済みポリシーは適用され続ける場合があります。

## ヘルプを見る

項目の横の小さな **i** をクリックすると説明が表示されます。外側をクリックするかEscapeを押すと閉じます。リストはスクロール可能なボックス内にあります。ボックスをスクロールして続きを表示します。検索は項目を削除せず、表示中のリストを絞り込みます。

カスタムルールには専用の[コードマニュアル](../code-manual/ja.md)があります。エディター、有効化、ログ、ファイルアクセス、対応APIを説明します。

## ネイティブアプリ

Apps対象の+ピッカーでインストール済みアプリを選びます。**これら以外のアプリをすべてブロック**すると許可リストになります。システムアプリ、ブラウザー、Vault自体はネイティブアプリのブロック対象外です。

ブロックしたアプリには終了を要求します。**ブロックしたアプリに再度終了を要求する間隔（分）**で再試行を設定します。Webサイトのリダイレクト、ページの一時停止、フィードの非表示はブラウザー拡張機能が適用し、ネイティブアプリ操作にはなりません。

## コンテンツのタグ付け

各グループは割り当てられたプラットフォームのコンテンツに、独自のタグツリーとモデル設定でタグを付けます。各プラットフォームは1つのグループに属します。作成時に選び、後から変更できません。ブロックグループの予定やフィルターはタグ付けを制御しません。設定 で有効にし、各グループの **タグ付けを一時停止 / タグ付けを再開** を個別に使います。**アクティビティ → 記録** でプラットフォームフィードの記録を止めると、そのタグ付けも止まります。

### タグとモデル設定

タグを作成して意味を説明し、ツリーで親を設定/解除します。ドラッグすると枝を移動します。明確な説明は似たタグの識別に役立ちます。グループごとに設定は独立しています。**タグの最低信頼度** は予測タグに必要な根拠レベルを1～5で設定します。新規グループは4（強い根拠）です。タグ数の目標はなく、タグなしになる場合もあります。**タグ付けの指示** はグループの希望を記録します。通常の編集は自動保存され、各グループは明示的に選んだ接続、モデル、推論強度を使います。

### AI 接続

設定 の選択肢は ChatGPT subscription、OpenAI API、Gemini API、Grok API です。サブスクリプションは Vault のサインインと対象プランを使います。API キーは選択したプロバイダーの課金と利用上限に従います。プロバイダーを選び、共通ドロップダウンの直下にキーを入力します。キー変更は自動保存され、欄を空にすると削除されます。**モデル一覧を取得** でモデルを取得し、コンテンツのタグ付け または custom-rule グループで選びます。取得しただけでは選択されません。

**推論の強さ** はモデルの思考量です。対応モデルでは Model default、Low、Medium、High を選べます。新規選択は Medium から始まり、既存の選択は保持されます。高い強度は時間とトークンを増やす場合があります。タグ付けでは Web 検索が常に有効で、使用時期はモデルが決めます。検索と構造化タグ付けに対応するモデルを選んでください。失敗/利用不能時も有効なキャッシュ結果は保持され、新しい項目は **クラウド分類を再試行** を選ぶまで未解決です。Vault は自動でプロバイダーを切り替えません。接続ごとに再試行間隔と上限があります。拡張機能で **+ tag** を押し、検索して追加します。削除操作またはタグを選択して Delete を1回押すと削除できます。**未タグ** はタグなしで完了、**タグ付け中** は結果待ちを示します。修正内容はその項目で優先されます。


## アクティビティ

アクティビティ は有効なアプリ使用、Web サイト訪問、対応する **閲覧したコンテンツ** をローカル記録します。グラフは記録データを示し、空白でも PC のアイドル状態を証明しません。期間を選びます。**タイムライン** は時刻別、**合計** は時間合計、**時間間隔** は各間隔の利用を縦ブロックにまとめます。**色** はクリックできる凡例で、ソースを選ぶとグラフを絞れます。日付を選ぶとその日以降の使用を表示します。

### アクティビティ groups

選択したアプリと Web サイトを Usage にまとめて表示するグループを作成します。**Merge** は アクティビティ 全体でメンバーの名前と色を統一します。アクティビティ group は記録使用を整理するもので、ブロックグループ/タグ付けグループとは別です。エディターで **Save** を明示的に押します。

### 記録 と retention

**記録** でカテゴリまたは個別ソースの記録を切り替えます。**保持** は履歴の保存期間、**常に** は自動期限なしです。個別設定は上位設定に従う場合があります。記録を止めると新しい記録が停止し、履歴を削除すると記録済み項目が消えます。プラットフォームフィードは、開いたかどうかにかかわらず対応ページに表示されたコンテンツを収集します。**タグ付け対応** フィードは記録中に コンテンツのタグ付け へ提供できます。保持設定はアプリ/サイト使用とは別です。タグ付けグループを一時停止しても記録自体は停止しません。

## 設定

設定 でインターフェース言語を選択します。項目の説明は選択言語の Info ボタンにあります。

## 保存とトラブルシューティング

Vaultと分類器の通常編集は自動保存されます。アクティビティグループの編集は**保存**を使います。追加、削除、モデルダウンロード、接続テスト、モデル一覧取得は明示的な操作です。

タグがない場合はブラウザー接続、全体のタグ付けスイッチ、グループの一時停止状態、プラットフォーム記録、モデルダウンロードを確認します。調査が動かない場合は同意、グループ選択、プロバイダー認証情報、調査モデル、調査状態を確認します。リンクグループを編集できない場合はプログラムを再接続するか、表示に従って凍結を解除します。
