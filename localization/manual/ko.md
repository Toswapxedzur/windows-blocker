# Windows Vault 사용자 설명서

Windows Vault에는 세 페이지가 있습니다. **Vault**는 native app을 차단하고, **분류기**는 지원되는 브라우저 콘텐츠에 태그를 달며, **활동**은 기록된 사용을 보여 줍니다. 브라우저 확장 프로그램은 지원 콘텐츠를 수집하고 브라우저 차단을 적용합니다. 사용하는 브라우저에 설치하고 연결하세요.

## 빠른 시작

1. **Vault**에서 차단 그룹과 Apps 대상을 추가한 뒤 + 선택기로 앱을 고릅니다.
2. 그룹의 차단 방식을 고르고 활성화합니다.
3. **분류기**에서 그룹을 만들고 플랫폼을 선택한 뒤 설명과 태그를 추가합니다.
4. 로컬 모델 등급을 선택하고 필요하면 내려받습니다. 분류기 설정에서 태그 지정을 켜고 그룹을 다시 시작합니다.
5. 연결된 브라우저에서 지원 콘텐츠를 엽니다. 태그로 차단을 제어하려면 브라우저 차단 그룹에 태그 필터를 설정합니다.

## 차단 그룹

**차단 그룹**은 차단 정책을 적용합니다. **분류기 그룹**은 콘텐츠에 태그를 지정하며, 그 자체로는 차단하지 않습니다.

1. 차단 그룹을 추가하고 이름을 지정하세요.
2. **적용 대상**에서 대상을 선택하세요.
3. 차단을 적용할 시점을 선택하고 일정이나 시간 할당량을 설정하세요.
4. 그룹을 활성화하세요. 대상에는 그룹 정책이 적용됩니다.

일반적인 편집은 자동으로 저장됩니다. 오류가 나면 편집이 승인되지 않은 것이므로 필드를 수정하고 다시 시도하세요. 설정은 유지하면서 정책을 멈추려면 그룹을 비활성화하세요. **그룹 삭제**는 그룹을 제거합니다. 그룹을 끌어 순서를 바꾸세요. 한 대상에 여러 그룹이 적용될 수 있으며, 하나를 잠시 미뤄도 다른 그룹의 차단은 해제되지 않습니다.

**내보내기**는 그룹 구성을 복사합니다. **가져오기**는 확인 후 선택한 그룹의 구성을 바꿉니다.

### 시간 할당량 및 일정

**즉시 차단**은 활성 그룹이 대상과 일치하고 일정이 활성일 때 적용됩니다. **시간 할당량을 다 쓰면 차단**은 할당량이 소진될 때까지 일치하는 사용을 허용합니다.

할당량은 분 단위, 재설정 간격은 시간 단위로 설정하세요. 롤링 한도는 직전 창의 사용량을 셉니다. 자정 재설정은 롤링 한도도 포함해 현지 시각 자정에 새 기간을 시작합니다.

활성 요일과 선택적 현지 시간 창을 한 줄에 하나씩 선택하세요(예: **09:00-12:00**). 창 목록이 비어 있으면 선택한 요일 전체에 적용됩니다. 창은 같은 날 시작 시각보다 늦게 끝나야 합니다. 밤을 넘기는 일정은 날짜별로 나누세요.

### 잠시 미루기

각 차단 그룹에서 미루기를 설정하세요. **차단 일시 중지**는 해당 그룹의 정책을 지정한 시간 동안 중단합니다. **시간 할당량에 추가**는 시간 제한 그룹에 사용할 수 있는 분을 더합니다. 실제로 사용한 추가 할당량만 미룬 시간에 포함됩니다. 사용하지 않은 추가 할당량은 다음 재설정 때 만료됩니다. 롤링 한도에서는 한 창 뒤에, 설정에 따라 자정에 더 일찍 만료됩니다.

**활성화 지연** 중에는 차단이 계속되고 미루기가 늦게 시작됩니다. **대기시간**은 미루기가 끝난 뒤 다음 요청 전까지 기다리는 시간입니다. **필요한 확인 횟수**는 확인 단계 수를 지정합니다. 그룹 동결 전에 허용한 경우에만 동결된 그룹에서 미루기를 사용할 수 있습니다.

### 편집 잠금과 PIN

**동결**은 일반 편집을 막습니다. 해제하려면 5초 간격으로 10회 확인하고, 설정된 대기 시간 및 6자리 PIN이 있다면 입력해야 합니다. **해제 전 대기**는 0~72시간입니다. 0은 추가 대기가 없다는 뜻입니다.

동결된 동안 대기 시간을 늘리고 PIN이 없다면 추가할 수 있습니다. 그룹을 해제할 때까지 이 조건을 완화할 수 없습니다. 삭제에도 남은 대기 시간과 PIN이 적용됩니다.

### 연결된 그룹

**연결**을 사용하면 다른 Vault 프로그램에서 명시적으로 선택한 그룹을 이어 줍니다. 연결된 그룹은 이름, 지원되는 정책 설정, 대상, 사용량, 동결 조건을 공유합니다. 각 프로그램은 지원하는 대상 유형을 편집하고 적용하며, 다른 대상 항목은 연결된 프로그램에서 사용할 수 있습니다. 연결을 해제해도 그룹과 설정은 유지됩니다.

연결된 구성원이 오프라인이면 편집할 수 없을 수 있습니다. 다시 연결하려면 Windows Vault과 연결 브라우저를 여세요. 구성원이 오프라인이어도 로컬 저장 정책은 계속 적용될 수 있습니다.

## 도움말 보기

필드 옆의 작은 **i**를 클릭하면 설명을 볼 수 있습니다. 바깥을 클릭하거나 Escape를 눌러 닫으세요. 목록은 스크롤 가능한 상자 안에 있습니다. 더 보려면 상자 안을 스크롤하세요. 검색은 항목을 삭제하지 않고 보이는 목록만 필터링합니다.

사용자 지정 규칙에는 별도의 [코드 설명서](../code-manual/ko.md)가 있습니다. 편집기, 활성화, 로그, 파일 접근, 지원되는 API를 설명합니다.

## Native 앱

Apps 대상의 + 선택기로 설치된 앱을 고르세요. **이 앱 외에는 모두 차단**하면 목록이 허용 목록이 됩니다. 시스템 앱, 브라우저, Vault 자체는 native app 차단에서 제외됩니다.

차단된 앱에는 종료를 요청합니다. **차단된 앱에 (분)마다 다시 종료 요청**은 재시도를 제어합니다. 웹사이트 리디렉션, 페이지 일시 중지, 피드 숨기기는 브라우저 확장 프로그램이 수행하며 native app 작업이 아닙니다.

## 콘텐츠 태그 지정

각 그룹은 지정된 플랫폼의 콘텐츠에 자체 태그 트리와 모델 설정을 사용해 태그를 지정합니다. 각 플랫폼은 한 그룹에 속합니다. 생성 시 선택하며 이후 변경할 수 없습니다. Blocking 일정과 필터는 태그 지정을 제어하지 않습니다. Settings에서 활성화하고 그룹마다 **태그 지정 일시 중지 / 태그 지정 다시 시작**을 따로 사용하세요. **활동 → 기록**에서 플랫폼 피드 기록을 끄면 태그 지정도 중단됩니다.

### 태그와 모델 설정

태그를 만들고 의미를 설명하며 트리에서 부모를 지정하거나 제거합니다. 태그를 끌면 가지를 옮깁니다. 명확한 설명은 모델이 비슷한 태그를 구분하도록 돕습니다. 각 그룹 설정은 독립적입니다. **최소 태그 신뢰도**는 예측 태그마다 필요한 증거 수준을 1–5로 지정합니다. 새 그룹은 4(강한 근거)에서 시작합니다. 목표 태그 개수는 없으며 항목에 태그가 없을 수도 있습니다. **태그 지정 지침**는 그룹별 선호 사항을 저장합니다. 일반 편집은 자동 저장되고 각 그룹은 명시적으로 선택한 connection, model, reasoning effort를 사용합니다.

### AI 연결

Settings에는 ChatGPT subscription, OpenAI API, Gemini API, Grok API가 있습니다. 구독은 Vault 자체 로그인과 대상 요금제를 사용합니다. API 키에는 선택한 제공자의 API 요금과 한도가 적용됩니다. 제공자를 선택하고 공통 드롭다운 바로 아래에 키를 입력합니다. 키 변경은 자동 저장되며 필드를 비우면 키가 삭제됩니다. **모델 목록 가져오기**로 모델을 가져온 뒤 콘텐츠 태그 또는 custom-rule 그룹에서 모델을 선택하세요. 가져오기만으로 모델이 선택되지는 않습니다.

**추론 강도**는 선택된 모델의 추론 수준입니다. 지원되는 경우 Model default, Low, Medium, High를 선택합니다. 새 선택은 Medium에서 시작하고 기존 선택은 저장된 대로 유지됩니다. 높은 수준은 시간과 토큰을 늘릴 수 있습니다. 태그 지정의 웹 검색은 항상 활성화되며 모델이 사용 시점을 결정합니다. 검색 및 구조화된 태그 지정을 지원하는 모델을 선택하세요. 실패하거나 사용할 수 없는 요청도 유효한 캐시 결과를 유지합니다. 새 항목은 **클라우드 분류 다시 시도**을 선택할 때까지 미해결 상태입니다. Vault는 제공자를 자동 전환하지 않으며 연결마다 재시도 간격과 횟수 제한이 따로 있습니다. 브라우저 확장에서 **+ tag**를 눌러 검색 후 추가하세요. 제거 컨트롤을 사용하거나 태그를 선택한 뒤 Delete를 한 번 눌러 제거합니다. **태그 없음**는 태그 없이 완료, **태그 지정 중**은 결과 대기 중을 뜻합니다. 해당 항목에는 사용자의 수정이 우선합니다.


## 활동

Activity는 활성 앱 사용, 웹사이트 방문, 지원되는 **본 콘텐츠**를 로컬에 기록합니다. 차트는 기록된 데이터를 보여 주며 빈 곳이 PC이 유휴 상태였음을 증명하지는 않습니다. 날짜 범위를 선택합니다. **타임라인**은 하루 중 시간별 사용을, **합계**는 기간 합계를, **시간 간격**은 각 간격의 사용을 세로 블록으로 표시합니다. **색상**는 클릭 가능한 범례입니다. 소스를 선택해 차트를 좁힙니다. 날짜를 선택하면 그날부터의 사용을 봅니다.

### 활동 그룹

Usage에서 선택한 앱과 웹사이트를 함께 보려면 그룹을 만듭니다. **Merge**는 활동 전체에서 구성원에게 같은 이름과 색을 적용합니다. 활동 그룹은 기록된 사용을 정리하며 blocking group이나 콘텐츠 태그 group과 별개입니다. 편집기에서 **Save**를 명시적으로 누릅니다.

### 기록 및 보관

**기록**에서 카테고리나 개별 소스별 기록을 켜거나 끕니다. **보관**은 기록 보관 기간, **항상**는 자동 만료 없음을 뜻합니다. 개별 선택은 상위 설정을 따를 수 있습니다. 기록을 끄면 새 기록이 중단되고 기록 삭제는 저장된 항목을 제거합니다. 플랫폼 피드는 페이지를 열었는지와 관계없이 지원 페이지에 표시된 콘텐츠를 수집합니다. **태그 지정 지원** 피드는 기록 중 Content tagging에 제공될 수 있습니다. 보관 설정은 앱 및 웹 사용과 별도입니다. 태그 지정 그룹을 일시 중지해도 기록 자체는 중단되지 않습니다.

## 설정

Settings에서 인터페이스 언어를 선택합니다. 선택한 언어의 Info 버튼에서 필드 설명을 볼 수 있습니다.

## 저장 및 문제 해결

일반적인 Vault 및 분류기 편집은 자동 저장됩니다. 활동 그룹 편집은 **저장**을 사용합니다. 추가, 삭제, 모델 다운로드, 연결 테스트, 모델 목록 가져오기는 명시적인 작업입니다.

태그가 없다면 브라우저 연결, 전체 태그 지정 스위치, 그룹 일시 중지 상태, 플랫폼 기록, 모델 다운로드를 확인하세요. 조사가 실행되지 않으면 동의, 그룹 선택, 제공자 자격 증명, 조사 모델, 조사 상태를 확인하세요. 연결 그룹을 편집할 수 없다면 관련 프로그램을 다시 연결하거나 안내에 따라 동결을 해제하세요.
